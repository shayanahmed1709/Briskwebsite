# BRISK — Cybersecurity Reimagined

Next.js 14 (App Router) marketing site for BRISK cybersecurity.

## Stack

- Next.js 14 App Router
- Tailwind CSS (custom BRISK theme)
- Framer Motion
- Lucide React

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Hero video

Place your hero loop at:

```
public/videos/hero.mp4
```

Until the file is present, the hero falls back to a dark navy CSS gradient.

## Build

```bash
npm run build
```
